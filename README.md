# Todo Tracker – Task Management Web Application

A simple and interactive Todo Web Application built using **React.js** and **React Context API**. This application helps users manage their daily tasks through a clean and user-friendly interface.

## 🌐 Live Demo

[**View Todo Tracker**](https://todotraccker.netlify.app/)

## 🚀 Features

- **Task Management:** Add and manage daily tasks.
- **Context API:** Uses React Context API for centralized state management and sharing data across components.
- **Dynamic UI:** Automatically updates the interface when the application state changes.
- **Reusable Components:** Structured using reusable React components.
- **Responsive Design:** Designed to provide a smooth user experience across different screen sizes.

## 🛠️ Tech Stack

- **Frontend:** React.js
- **State Management:** React Context API
- **Languages:** JavaScript, HTML, CSS
- **Deployment:** Netlify
- **Development Tools:** VS Code, Git, GitHub

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project directory**

```bash
cd Todo-Tracker
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open in browser**

Visit the local URL displayed in your terminal.
